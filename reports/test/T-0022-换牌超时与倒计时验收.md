# T-0022 · 换牌超时兜底与倒计时验收（D-267 / issue #99）

- **日期**：2026-10-21
- **对象**：`server/src/room/mulligan-timeout.ts`（新）、`server/src/index.ts`（计时器 / 快照 / 拒绝广播）、
  `core/src/rules/mulligan.ts`（删时间窗）、`client/src/TableScreen.tsx`（倒计时与按钮态）
- **依据**：issue #99、ADR-0056、ADR-0048（换牌阶段）、ADR-0017（服务端唯一时钟）
- **基线**：`master` 上 D-266 之后（`c50d68e`）

## 1. 结论

**可发布。**

issue #99 报的三件事（英文报错、换牌失败、倒计时是「—」）全部消掉，且 Era 提的三条要求
（换牌时长跟随回合时限 / 桌面显示倒计时 / 到点自动不换牌开局）在生产形态实测生效。

关键点是**根因不是「玩家操作失败」，而是服务端超时兜底自己坏了**：
`handleMulliganTimeout` 构造的系统 Intent 漏了 `payload.returns`，被规则拒掉 →
换牌阶段关不掉 → 拒绝原因还被广播给全房玩家。所以修的不是界面文案，是那条链。

## 2. 根因与证据

| 环节 | 事实 | 证据 |
| --- | --- | --- |
| 兜底 Intent 缺参数 | `{ type, actor, playerId, seq, reason }`，没有 `payload` | 修前 `index.ts` `handleMulliganTimeout` |
| 规则拒绝 | `strListArg(undefined)` → `null` → `CARD_NOT_IN_ZONE`，文案「returns 必须是 uid 数组」 | `core/rules/mulligan.ts` |
| 拒绝被广播 | system Intent 无 socket → `emitGameOut` 走 `io.to(room)` 分支 | `index.ts` `emitGameOut` |
| 阶段关不掉 | 兜底失败后，未确认方永远停在 `mulligan` | 玩家再提交 → 「时间窗已过」 |
| Era 那一局 | replay 的 `intents` 里**只有 AI 的 mulligan**，玩家的提交全被拒 | `app/replays/bd0808bc-…json` |

截图时间（16:47:44 / 16:48:13）与该局 `startedAt`（16:47:10）之后 30 秒整点吻合 ——
第一个报错正是**超时兜底触发那一刻**，不是 Era 点了什么。

## 3. 验收项与实测结果

| 项 | 期望 | 实测 | 判定 |
| --- | --- | --- | --- |
| 超时兜底能关掉换牌阶段 | 双方向被提交「不换牌」→ 进第一回合 | 单测：`applyIntent` 接受，产生 `mulligan:done`；双方提交后 `phase !== 'mulligan'` | ✅ |
| 兜底 Intent 带参数 | `payload.returns === []` | 单测断言 + 跑一遍引擎 | ✅ |
| 缺参数仍被拒（不放宽规则） | 拒绝，`CARD_NOT_IN_ZONE` | 单测 | ✅ |
| 换牌时长跟随房间档位 | 建房选 30s → 换牌 30s | 生产实测：`计时 31s`（30s 档位 + 1s 取整） | ✅ |
| 桌面显示倒计时 | 顶栏「计时 Ns」、提示条「剩余 N 秒」 | 生产实测：`计时 31s`，提示条「（剩余 31 秒，到点自动不换牌开局）」 | ✅ |
| 到点自动开局 | 不点任何按钮也进第一回合 | 生产实测：静置 31s 后顶栏变「第 1 回合」 | ✅ |
| 顶栏不再显示「—」 | 换牌阶段有具体秒数 | 生产实测 + E2E 断言 `/计时 \d+s/` | ✅ |
| 不再出现英文报错 | 界面无「returns」、无「时间窗已过」 | 生产实测：两项均为 `false` | ✅ |
| 归零后不再给提交入口 | 按钮变「换牌时间到，正在开局…」 | 客户端实现（`mulligan-expired`） | ✅ |
| system Intent 拒绝不广播 | 只记 `fastify.log.warn` | 代码 + 本次生产日志无 `game:events` 拒绝 | ✅ |

### 3.1 生产形态复验（390px 视口，`http://127.0.0.1:3100`）

```
clock@start: 计时 31s
hint: 开局换牌：选出手牌里不想要的 →「确认换牌」；不想换直接点「不换牌」（剩余 31 秒，到点自动不换牌开局）
turn after timeout: 第 1 回合
log tail: …电脑 完成换牌 Probe267 完成换牌
hasReturnsError: false
hasExpiredText: false
```

「电脑 完成换牌」之后紧跟「Probe267 完成换牌」，说明**服务端替静置的玩家提交了跳过**，
而不是靠客户端补点。
