### 2.3 验收 3：对手视角点开我方费用区，能看到全部卡牌内容

**核查结论：桌面这半本来就没问题**，`TableScreen.tsx` 的对手费用区是
`ZoneBox content='float'`，点开浮窗即可看卡面。#142 只藏了战报推送。

但「本来没问题」不等于「有保障」—— 此前没有任何用例，所以补了一条：

`zone-inspect.spec.ts`「对手费用区可点开查看具体卡牌（#143）」：

1. 等到电脑费用区非空（income 2/回合 + AI 主动充能）；
2. **未点开时**框内不铺卡（B2-3：默认只显示区名 + 张数）；
3. 点开后浮窗内的卡数 == 区域张数；
4. 每张卡面文本非空（牌名 / 费用 / 力量可读）；
5. 关闭后浮窗消失。

## 4. 覆盖盲区（如实登记）

1. **多人桌**：目前恒 2 席，`viewer` 与 `playerId` 的比较是按两人写的；多于两人时要改成
   「任意第三方视角」判定（表本身不需要改）。
2. **`viewer = null` 时的公开位移**：本条定为「照常念卡名」，但没有真实调用点会传 `null`
   （`useRoom` 恒传 `me`），属防御性行为，无端到端验证。
3. **桌面卡面可读性**只断言了「文本非空」，没有断言具体字段（牌名 / 费用 / 力量分别可见）；
   卡面排版归 X-14 / X-15。

## 5. 与 issue 原文的偏离

| issue 写法 | 实际做法 | 原因 |
| --- | --- | --- |
| 「B 是独立改动点，需实测确认对手视角能否看见牌名」 | 实测**已可见**，不改代码，只补 E2E | 对手费用区一直是 `content='float'`；#142 只藏了战报 |
| 「对手充能后战报显示具体卡名」 | 额外加**归属前缀**（`电脑 将 X 置入费用区`） | 双方共用一列战报，只写卡名分不清是谁充的；自己文案保持原样 |
| 「补一条 viewer=null 不泄露手牌的用例」 | 该用例**保留未改**；另加「公开区不受视角影响」 | fail-closed 只对隐藏区流向有意义 |
