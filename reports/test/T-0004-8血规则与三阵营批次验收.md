## 1. 结论

本批次把 Demo 从「15 血旧版 + 单一阵营」整体切换到「8 血版 + 三阵营 + BO1/BO3」，
自动化验收全部通过：**core 137 / server 60 / E2E 17**，typecheck 与 lint 均 0 错误。

「有条件」的三条条件：

1. **拟真覆盖不足**：E2E 为桌面 Chromium 双上下文，未在真实手机 / 触屏设备实测；
   移动端仅做三档视口渲染验证（375 / 768 / 1440）。
2. **仍有 7 条假设未拍板**：H25（换牌窗 30s）、H26~H31（效果口径）、H33（BO3 第 3 局重掷）、
   H35（展示先置底再触发）、H36（房主开下一局）。这些都有可运行实现，但口径可能被 Era 改判。
3. **B1 功能缺口**：卡组编辑可保存多套卡组，但**尚未接入开局**（服务端按所选阵营装配默认 30 张）。

以上均不阻塞「双人对战 Demo 可玩」，故不判阻塞。

### 3.3 规则口径专项（单测钉住的关键条款）

| 条款 | 断言要点 | 位置 |
| --- | --- | --- |
| 8 血 / 先手 5 张 / 后手 6 张 | `INITIAL_HEALTH`、双方起手张数 | `rules.test.ts` 开局组 |
| 先攻首回合抽 0 且自动充能 0 | 卡组顶不动，手牌不增 | `rules.test.ts` |

| `maxCost` 按 `chargeCount` 取 1/3/5/10 | 超额出牌被拒 | `rules.test.ts` 出牌组 |
| 随从费用 −1 | 支付张数 = 费用 − 1，0 费可直接出 | `rules.test.ts` |
| 前排规则 | 对方有随从时打脸被拒（`FRONT_LINE`），休眠随从也算 | `rules.test.ts` 打脸组 |
| 打脸无力量门槛 | 1 力随从空场也造成 1 点且不自爆 | `rules.test.ts` D-227 |
| 打脸伤害分档 1/2/3 | 4–6 力 2 点、7+ 力 3 点、卡面 `damage` 优先 | `rules.test.ts` |
| 指挥官每战斗阶段 1 次、不能打随从 | 第二次拒 `COMMANDER_ATTACK_USED`；先攻首回合拒 | `rules.test.ts` 指挥官组 |
