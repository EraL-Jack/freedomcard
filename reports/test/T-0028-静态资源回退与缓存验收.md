# T-0028 · 静态资源回退与缓存验收（D-273 / issue #107）

- **日期**：2026-10-21
- **对象**：`server/src/static-serve.ts`（新，`isSpaRoute` / `cacheControlFor`）、`server/src/index.ts`
  （静态托管注册与 notFoundHandler）、`app/scripts/build-atomic.mjs`（新构建脚本）、
  `client/index.html`（资源失败兜底提示）
- **依据**：issue #107、ADR-0062（资源缺失必须 404 + 按内容哈希分档缓存）、ADR-0002
- **基线**：`master` 上 D-272 之后（`a8db8c6`）

## 1. 结论

**可发布。**

缺失资源不再被回成 `index.html`：生产形态下 `/assets/*` 的缺失文件返回 **404 + `application/json`**，
带哈希的资源改为 `immutable` 长缓存、`index.html` 改为 `no-cache`；
构建改成「先构建到临时目录 → 增量复制 → 最后换 index.html」，消除重建空窗；
客户端在样式表 / 脚本加载失败时给出「请刷新重试」红条，不再静默白纸。

## 2. 缺陷复现（修复前，3100 现场）

```
$ curl -s -D - -o /dev/null http://127.0.0.1:3100/assets/index-DOESNOTEXIST.css
HTTP/1.1 200 OK
content-type: text/html
content-length: 446          ← 内容其实是 index.html
```

浏览器按 MIME 拒绝解析样式表，且**不重试、不报错**，页面变成白底黑字。

## 3. 改动清单

| # | 改动 | 位置 |
| --- | --- | --- |
| 1 | `isSpaRoute(url)`：只有像前端路由的路径才回 index.html | `static-serve.ts` |
| 2 | `cacheControlFor(filePath)`：`assets/` → immutable；`*.html` → no-cache | 同上 |
| 3 | 静态托管注册 `setHeaders`；notFoundHandler 用 `isSpaRoute` 判定，非路由回 404 JSON | `index.ts` |
| 4 | `build:atomic`：构建到 `dist.new` → 增量复制进 `dist` → 最后换 `index.html`，保留上一代资源 | `app/scripts/build-atomic.mjs` |
| 5 | 客户端 `link`/`script` error → 顶部红条（`data-testid="asset-error"`，样式全内联） | `client/index.html` |

## 4. 验证

### 4.1 单测（447 → 454，server 153 → 160）

`static-serve.test.ts` 7 条：

| 组 | 断言 |
| --- | --- |
| SPA 回退范围 | `/`、`/room/ABCDEF`、`/table`、`/a/b/c`、带 query/hash → true；`/assets/*`、`/assets/`、`/favicon.ico`、`/manifest.webmanifest`、`/nested/dir/file.css` → false；`/socket.io/`、`/health` → false |

### 4.3 生产实测（3100 + 公网 frp-cup.com:57732）

| 请求 | 结果 |
| --- | --- |
| `GET /assets/index-DOESNOTEXIST.css` | **404** + `content-type: application/json` |
| `GET /assets/index-DssWLm9t.css` | 200 + `cache-control: public, max-age=31536000, immutable` |
| `GET /` | 200 + `cache-control: no-cache` |
| `GET /room/ABCDEF`（前端路由） | 200 html + `cache-control: no-cache` |

## 5. 已知边界

| 项 | 说明 |
| --- | --- |
| 开发态 Vite | 仍会把缺失 `.css` 回成 `200 + index.html`（Vite 自身 SPA 回退）。只影响本地，写用例要模拟请求失败而非不存在的路径（README §10 第 25 条） |
| 目录 rename | 本机 Windows 对有内容的目录改名返回 `EPERM`，故原子构建改用「增量复制 + 最后换指针」 |
| 上一代资源 | `dist/assets` 会多留一版（下一次构建清掉），保证「刚加载完旧页面的客户端」不 404 |
