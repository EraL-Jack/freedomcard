## 3. 断言钉住的四件事

新增用例「展示期间卡片停在展示区，结算完才回牌库底」逐条 reduce 事件流，逐点检查：

| 断言 | 意义 |
| --- | --- |
| 每条 `card:revealed`（`reason='star-reveal'`）之后，该卡**在 `zones.reveal`、不在 `zones.deck`** | 「翻开即在展示区」——不是等结算完才挪走，也不是翻开的同一刻就算已置底 |
| `deck:put-bottom` 出现在**最后一张翻开之后**，且 `star:mark` 在两者之间 | 归位排在这一批的末尾，效果确实在展示期间结算 |
| 归位那一刻 `zones.reveal` 为空 | 三张一起回底，不会残留 |
| 收尾：牌库末尾三张 = 翻开顺序 | 归位顺序与 docs/17 §2.1 一致 |

配套的既有用例「展示批次里含『展示时抽牌』」继续通过，证明改动没有破坏「抽到第 4 张」这条核心不变量。
