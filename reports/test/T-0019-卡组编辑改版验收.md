新增用例钉住的是「三套开箱即用」这个事实：

- 阵营齐全（blade / frost / star）；

### 2.2 端到端

| 用例 | 结果 |
| --- | --- |
| `deck.spec.ts`（原有：编辑 → 设为开局 → 建房 → 手牌来自自建卡组） | ✅ 2.6s |
| `deck-editor.spec.ts` 新增 4 条 | ✅ 4.4s |

新增 4 条：

1. 首次进入预置三套，每套 30 张、判为合法、可直接设为开局；
2. 详情浮层内加 2 张 → 已选区出现 → 关闭浮层后在已选区减 1，总数回落；
3. 同名上限：加到 3 后 ＋ 置灰，**强制点击也不会变成 4**；
4. 分类统计：`随从 0 · 法术 0 · 设置 0` → 加 2 张变 `随从 2`，减 1 张变 `随从 1`。

全量回归 **24/24 通过**（2m 6s），`typecheck` 与 `lint` 均 0 error。

## 3. 遗留与依赖

| 项 | 说明 |

| H38 待选范围 | 待选区显示**完整卡池**（含已加入的卡），而非只显示未选。理由：Era 同时要求「点条目看详情 + 加减」，移出后就点不到已选卡的详情 |
