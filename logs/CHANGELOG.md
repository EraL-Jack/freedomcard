  2. **本机 `github.com:443` 间歇性不可达**（`api.github.com` 一直通）。表现为 `Recv failure: Connection was reset` 或 `Could not connect after 21s` —— **重试即可**，第 2 次成功
  3. 备用通道：GitHub Git Data API（blob → tree → commit → ref）可在 443 全断时写入提交，但 **GitHub 会覆盖 author/committer 为令牌身份、并按自己的方式生成 tree**，导致两端 SHA 必然不同；仅作兜底，最终仍应以真实 `git push --force` 收口（远端内容经 blob 逐文件比对确认完全一致后才覆盖）
- 遗留提示：仓库可见性为 **public**（匿名可访问）；若需改为私有，由 Era 在 Settings → Danger Zone 自行切换

## D-108 · 2026-10-13 23:50 · 主界面表单两个实测问题修复（输入不可读 / 建房报天书错误）

## D-111 · 2026-10-14 02:40 · 对战桌格子铺满桌体（Era 实机反馈「格子不铺满」）

**交付件**：`client/src/TableScreen.tsx`

### 根因

- 每排加 `auto-rows-fr`（`grid-auto-rows: minmax(0, 1fr)`）——
  没有它，grid 行高仍是 auto（内容高），排高了行也不跟。
  格子是 grid 子项，默认 stretch，行满则格子满。

## D-129 后攻方换牌放开（X-17 拍板）

- 背景：Era 2026-10-19 拍板 X-17「放开，双方都能换」。原守卫 `turn !== 1` 使后攻方

- **规则**：双方各自**第一个充能阶段**均可换一次。判定从「第 1 回合」改为

  30s 窗外，放开等于没放。时长仍 30s（H25 待确认）。

  activeSeat 还是**刚结束回合**的人 —— 充能计数必须挂在 turn:changed 上。
- 客户端：换牌按钮窗口判定同步改为 chargeCount + firstChargeAt。

## D-156 基础文字色缺失：黑字压深底（对比度 1.2–1.4）

## D-163 穿透实操结论回填 docs/20（隧道类型选择 + IPv6 根因）

- **依据**：SakuraFrp 官方文档 `doc.natfrp.com/app/http.html`（Era 提供）。

  原因是 Windows 侧 `localhost` 优先解析到 IPv6 `::1`，而服务只监听 IPv4 `0.0.0.0`。
- **环境事实**：Era 的 `frpc.exe` 当前连的是 `218.12.120.170`（内地节点），
  与「TCP + HTTP 应用」组合冲突，需换非内地节点。
