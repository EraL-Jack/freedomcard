# 18. 卡牌文本规范（D-230）

> 目的：让三套卡（炎刃 / 霜律 / 星轨，共 45 张）的卡面读起来像同一个人写的，
> 并且**每个词都能在规则条文里找到对应**。
>
> 依据：`docs/10-卡牌样例.md`（Era 原始样例，ADR-0015 只抄不改）是格式基线。
> 本文只规定**怎么写**，不规定**写什么**——效果本身仍由各卡组设计稿决定。

---

## 1. 三条原则

1. **卡面只写规则，不写设计意图。** 意图写在卡面下方的引用块里（`>`），玩家在桌面上看不到。
2. **卡面用词必须在 §6 术语表里。** 表里没有的词，要么补进表，要么换词。
3. **一个触发一行，触发时机在行首。** 不允许把两个不同时机塞进一句话。

---

## 2. 条目结构

每张卡固定四段，顺序不变：

````markdown
#### 炎刃军先锋（随从）
`bladeVanguard`

```
【1】随从 / 力量值2 / 伤害值1
```

> 白板。1 费 2 力量值是基准线，也是充能素材。
````

| 段 | 内容 | 规则 |
| --- | --- | --- |
| 1 | 标题 | `#### 名称（类型）`；类型只能是 **指挥官 / 随从 / 法术 / 设置法术** |
| 2 | 标识 | 单独一行，行内代码包住 defId |
| 3 | 卡面 | 围栏代码块，**第一行必须是 §3 的格式**；效果从第二行开始 |
| 4 | 说明 | 引用块，写设计意图、数值理由、与规则的对应节号 |

**禁止**：

- 标题里写费用或力量值（`**炎刃军先锋** \`bladeVanguard\` — 1 费 / 2 力量值` ❌）
- 标题里塞 defId（`#### 炎刃军先锋（随从）\`bladeVanguard\`` ❌）
- 卡面里写 defId、节号、设计说明

---

## 3. 卡面第一行

### 3.1 指挥官

```
指挥官
Ⅰ ……
Ⅱ ……
```

- **只写类型**，不写费用（指挥官不通过支付打出）
- **不写力量值**：指挥官没有力量值，不参与任何比较（规则见 `16` §6.2.1）
- **不写伤害值**：基础 1 点，是通用规则，不逐卡标注（加成由效果文本单独写，如`本回合你的指挥官伤害值 +1`）
- **首行就是「指挥官」三个字**，不补 `伤害值1` 之类的数值——首行要表达的是「这张卡怎么用」，
  而指挥官的用法（每回合攻击 1 次）全部由通用规则承担，卡面不重复

### 3.2 随从

```
【费用】随从 / 力量值N / 伤害值N
```

**三个字段一律写全**，顺序固定：

| 位置 | 字段 | 例 |
| --- | --- | --- |
| 1 | `【费用】随从` | `【2】随从` |
| 2 | `/ 力量值N` | `/ 力量值2` |
| 3 | `/ 伤害值N` | `/ 伤害值1` |
| 4（可选） | `/ 嘲讽` | `/ 嘲讽` |

- `伤害值` 指**初始伤害值**：未受伤、未加成的卡面值。战斗中按分档规则重算时以它为准。
- 即使初始伤害值是 1，也**必须写出来**（`/ 伤害值1`），不允许省略。
- 嘲讽等关键词排在最后。

### 3.3 指挥官卡面不写什么

指挥官卡面只写 **Ⅰ / Ⅱ / Ⅲ 技能**。以下属于**通用规则**，不写进任何指挥官的卡面：

- 每回合一次攻击（打脸基础 1 点，可被效果加成）
- 攻击顺序、伤害结算、前排判定
- 指挥官的任何数值（力量值、伤害值都不写）

这样三套指挥官卡面的差异只体现在「资源 + 兑现」，不会因为通用规则不同而读起来不一样。

### 3.4 法术 / 设置法术

```
【费用】法术
【费用】设置法术
```

- 法术**不写力量值**（原样例即为空）
- **设置法术 = 设置在场上**（Era 2026-10-19 定名，原称「持续法术」）：出牌后**留在法术区**，
  持续提供光环或触发；普通法术结算后进墓地。
- 常驻型效果以 `设置：` 开头（`设置：敌方处于冻结状态的随从力量值 -1。`）；
  触发型效果直接写时机（`己方「炎刃」卡被除外时：抽 1 张。`）。

### 3.5 费用写法

| 位置 | 写法 | 例 |
| --- | --- | --- |
| 卡面第一行 | 全角方括号 + 阿拉伯数字 | `【2】` |
| 正文叙述 | 数字 + 空格 + 「费」 | `支付 2 费` |
| 表格 | 「费用」列，只写数字 | `2` |
| 卡面效果行 | 紧跟触发时机 | `攻击时【1】：` |

**`【N】` 只允许出现在两个位置**：

1. 卡面第一行——卡牌本身的费用（`【2】随从`）；
2. 效果行的时机之后——发动该效果的代价（`攻击时【1】：`）。

标题、说明块、正文叙述里都不写 `【N】`；正文要提费用时写「2 费」。

## 4. 效果文本

### 4.0 效果行的固定格式（「什么时候 → 花多少 → 做什么」）

一条效果**只有三个要素，顺序不变**：

```
[什么时候] [花多少]：[做什么]
```

| 要素 | 必填 | 写法 | 例 |
| --- | --- | --- | --- |
| **什么时候** | 必填（法术除外） | §4.1 的时机词，放行首 | `登场时`、`攻击时`、`每回合一次` |
| **花多少** | 选填 | `【N】` 紧跟时机，中间不加标点 | `攻击时【1】` |
| **做什么** | 必填 | 动词开头，句号结尾 | `冻结 1 个未冻结的敌方随从。` |

四条硬性细则：

1. **时机与费用之间不加任何标点**：`攻击时【1】：`，不写 `攻击时，【1】，`。
2. **费用只写一次**。`【N】` 本身就是代价，正文不再出现「支付 N 费」「可以支付」。
3. **不付费就不写费用位**：免费效果直接 `登场时：…`，不写 `【0】`。
4. **冒号统一全角「：」**，位置在「花多少」之后、「做什么」之前。

> **不发动 = 不付费**是通用规则，所以卡面**不用「可以」来表示可选**——
> `攻击时【1】：…` 已经隐含「你可以不花这 1 费、放弃这次效果」。

反例（全部来自本次修正前的卡面）：

| ❌ 错误写法 | 错在哪 | ✅ 正确写法 |
| --- | --- | --- |
| `【1】你的指挥官攻击时，可以支付 1 费，…` | 费用跑在时机前 + 重复 + 主语 | `攻击时【1】：…` |
| `Ⅰ 每回合一次【2】，可以…` | 逗号代替冒号 + 多余的「可以」 | `Ⅰ 每回合一次【2】：…` |
| `【2】每回合一次：…` | 费用跑在时机前 | `每回合一次【2】：…` |
| `当此卡被攻击时，…` | 时机不是规范词，且带主语 | `被攻击时：…` |
| `每当你有一个随从登场时，…` | 同上 | `其他己方「炎刃」随从登场时：…` |

> 本条对指挥官技能、随从效果、设置法术一律适用。
> 只有正文叙述（`6.1` 这类流程说明）保留「支付 2 费」的文字写法，**卡面内一律用 `【N】`**。

### 4.1 触发时机（行首，只能从下表取词）

> **例外**：法术直接写动作（`对敌方指挥官造成 2 点伤害。`）。
> 设置法术分两种：**光环**以 `设置：` 开头；**触发式**（如战旗）直接写时机词。

| 时机词 | 什么时候 | 例 |
| --- | --- | --- |
| `登场时：` | 从手牌打出并进入随从区 | `登场时：冻结 1 个未冻结的敌方随从。` |
| `攻击时：` | 宣告攻击后、结算前 | `攻击时：若目标处于冻结状态，本回合此卡力量值 +1。` |
| `被攻击时：` | 自身成为攻击目标 | `被攻击时：攻击者本回合力量值 -1。` |
| `被冻结时：` | 自身被赋予冻结 | `被冻结时：抽 1 张。` |
| `被除外时：` | 自身被移出游戏 | `被除外时：抽 1 张。` |
| `被破坏时：` | 自身离场进墓地 | `被破坏时：抽 1 张。` |
| `展示时：` | **自身**从卡组顶被展示 | `展示时：获得 1 层星轨。` |
| `每当你展示 1 张卡时：` | 任意展示发生（全局计数） | `每当你展示 1 张卡时：获得 1 层星轨。` |
| `其他己方「炎刃」随从登场时：` | 其他己方随从入场（不含自身）；卡名按实际替换 | `其他己方「炎刃」随从登场时：该随从本回合力量值 +1。` |
| `敌方随从被冻结时：` | 任意敌方随从被冻结 | `敌方随从被冻结时：抽 1 张（每回合最多触发 1 次）。` |
| `己方「炎刃」卡被除外时：` | 带条件的离场触发；卡名按实际替换 | `己方「炎刃」卡被除外时：抽 1 张。` |
| `每回合一次：` | 主动技能，不依附攻击 | `每回合一次【2】：冻结 1 个未冻结的敌方随从。` |
| `设置：` | 光环，常驻生效 | `设置：敌方处于冻结状态的随从力量值 -1。` |

**写法规则**：

- **只写时机，不写主语**：`被攻击时：`，不写 `当此卡被攻击时，`。
- **同一时机的多个动作合成一行**，用「；」连接：`登场时：冻结 1 个敌方随从；若该随从已处于冻结状态，改为抽 1 张。`
  （这是**缚锁者**的卡面例外：普通冻结效果一律写「未冻结的敌方随从」，只有卡面自带替代分支时才允许指向已冻结单位）
- **不同时机必须分行**，不允许把两个时机塞进一句。
- 时机词后面**直接跟冒号**；有费用时写成 `时机【N】：`。

### 4.2 目标

必须写**数量 + 归属**：

| ✅ | ❌ |
| --- | --- |
| 1 个敌方随从 | 1 个随从 |
| 1 个己方随从 | 自己随从 |
| 敌方指挥官 | 对面 / 敌人 |
| 所有敌方随从 | 全场随从 |

### 4.3 可选与次数

- 可选动作：`可以`（`可以被除外`）。**费用不需要用「可以支付」表达**，见 §4.0
- 次数限制：句末括号，`（每回合最多触发 1 次）`
- 叠加限制：句末括号，`（不可叠加）`

### 4.4 动作的标准说法

| 动作 | 写法 | 备注 |
| --- | --- | --- |
| 改变力量值 | `力量值 +1` / `力量值 -1` | 属性在前、增量在后，`+` 前留空格；不写「+1 力」 |
| 造成伤害 | `造成 N 点伤害` | 不写「打 N 血」 |
| 抽牌 | `抽 N 张` | 不说「摸牌」 |
| 置入费用区 | `置入费用区` | 不写「充能」「进伤害区」 |
| 置入墓地 | `置入墓地` | 不写「弃掉」 |
| 移出游戏 | `除外` | 不写「放逐」 |
| 召唤衍生物 | `召唤 1 个星灵（力量值1 / 伤害值1）` | 数值写在括号里，与卡面首行同格式 |

## 5. 成长与档位

**凡是靠某个累积量分档的效果，必须把档位表写进卡面**——玩家不该去翻设计稿。

### 5.1 标准写法

主句以冒号结尾，档位逐行缩进 2 空格，格式 `档位：效果`：

```
Ⅰ 每回合一次【2】：按除外区「炎刃」卡的数量，执行以下最多 3 个效果（每个效果最多一次）：
  1 个：从你的墓地选择 1 个力量值不高于该数量的随从，召唤
  3 个：选择 1 个己方随从，本回合力量值 +1
  5 个：选择 1 个力量值不高于该数量的敌方随从，破坏
  7 个：选择 1 个己方随从，本回合对指挥官伤害 +1
  9 个：选择 1 个己方随从，本回合攻击后重置（每回合最多 1 次）
```

### 5.2 星轨的写法

```
Ⅰ 攻击时【1】：按星轨层数从卡组顶展示，触发其中所有「展示时」效果，然后将这些卡按原顺序置入牌库底：
  0–2 层：2 张
  3–5 层：3 张
  6 层及以上：4 张
Ⅱ 每当你展示 1 张卡时：获得 1 层星轨（永久累积，不清零）。
```

### 5.3 硬性要求

每个成长资源必须在卡面里回答三个问题：

1. **怎么来**（`每当你展示 1 张卡时`）
2. **是否清零**（`永久累积，不清零`）
3. **兑现什么**（档位表）

缺一条都算卡面不完整。

## 6. 术语表（全游戏唯一口径）

| 正式术语 | 禁用 / 避免 | 说明 |
| --- | --- | --- |
| 费用区 | 充能区、伤害区、法力池 | 代码 `cost`；Era 已确认三者同义，**统一用费用区** |
| 墓地 | 弃牌区、坟墓、坟场 | 代码 `graveyard` |
| 除外区 | 放逐区、异次元 | 代码 `exile` |
| **力量值** | 力量、攻击力、身材 | 属性名。例外：4 张 Era 原文卡内的写法（§7.5） |
| **伤害值** | 伤害、攻击力 | 属性名，指卡面的**初始伤害值**；结算动作用「造成 N 点伤害」 |
| **初始伤害值** | 默认伤害、基础伤害 | 卡面 `伤害值N` 的正式叫法，用于与「加成后的当前伤害值」区分 |
| 指挥官 | 主将、领袖、英雄 | — |
| 随从 | 单位、生物、怪 | — |
| 衍生物 | token、召唤物 | — |
| 冻结 | 霜冻、冰冻、冰封 | 状态关键词；动词也用「冻结」 |
| 霜痕 | 霜冻值、冻结层数 | 霜律的累积资源 |
| 星轨 | 星痕、轨道值 | 星轨的累积资源 |
| 展示 | 翻牌、揭示、翻开 | 从卡组顶公开；**不是抽牌** |
| 嘲讽 | 护卫、挑衅 | 关键词 |
| 休眠 / 重置 | 横置 / 竖置、横牌 | 状态 |
| 登场时 | 入场时、召唤时、落地时 | 触发时机 |
| 破坏 | 击杀、消灭 | 随从离场进墓地 |
| 支付 | 花费、消耗 | 仅用于正文叙述；**卡面不写「支付」**，用 `【N】` |

> **「力量值」与「力量」**：卡面一律用「力量值」；「力量值提升，在每回合充能阶段执行」
> 是 Era 原文的固定句，保留原字。
>
> **「冻结」与「霜冻」**：卡面与规则条文统一用「冻结」；「霜冻」不再使用。

## 7. 数字与标点

| 项 | 规则 | 例 |
| --- | --- | --- |
| 数字 | 阿拉伯数字，不用中文数字 | `2 张`，不写「两张」 |
| 区间 | en dash `–`，两侧不加空格 | `0–2 层`、`1–3` |
| 大数连接 | 用「及以上」，不写 `5+` | `6 层及以上` |
| 句末 | 每条效果以句号结尾 | `抽 1 张。` |
| 括号 | 全角，仅用于次数/叠加限制 | `（不可叠加）` |
| 引号 | 卡名 / 卡名条件用直角引号「」 | `「炎刃」卡` |
| 空格 | 数字与汉字之间加空格 | `抽 1 张`、`支付 2 费` |

## 7.5 原文例外（重要）

有两类文本**不受本规范约束**，必须保留 Era 原字：

1. `docs/10-卡牌样例.md` 全文——ADR-0015 规定「只抄卡面，不解析效果」。
2. 12 号文档里标注「原文不动」的 4 张炎刃原始卡（`bladeVanguard` / `bladeScout` /
   `bladeTactician` / `bladeOrder`）。

`bladeLord` 是例外中的例外：**语义按原文，格式按本规范**——首行去掉力量值曲线、
`【2】` 从行首移到「每回合一次」之后、术语与空格归一，效果内容一字未改（差异逐条记在 12 号 §2.1）。

所以下面这些**看似违规、实则必须保留**：

| 原文用字 | 规范用词 | 处置 |
| --- | --- | --- |
| 伤害区 | 费用区 | 保留。Era 原文，alias 已在 §6 登记 |
| 力量值+1（无空格） | 力量值 +1 | 保留（仅限 4 张原文卡） |
| `力量值0-1-3-5 力量值提升，在每回合充能阶段执行` | `指挥官` | **不保留**：Era 2026-10-19 取消指挥官力量值后删除 |
| 1 个：/ 3 个： | 档位数字 | 保留（`bladeLord` 已按规范补空格为 `1 个：`） |

新增卡与改写卡一律按 §3–§7 执行。
