以下内容**仅供参考留痕，不是需求**：

如果希望尽快看到能打的第一版，建议第一版只做：

1. **2 人对战**，本地可建房、可加入、可重连。
2. **单一卡组**（10–15 张），只含 3 类卡：普通随从、直接伤害法术、治疗。
3. **回合流程**：抽牌 → 出牌（费用制）→ 攻击 → 结束回合。
4. **胜负**：一方血量为 0 即结束。
5. 界面：大厅 + 对战桌两页，竖屏可玩。

其余机制（关键词、连锁响应、卡组编辑、排行榜）留到 v0.2，靠规则插件机制增量加入 —— 这正好验证架构的解耦能力。
