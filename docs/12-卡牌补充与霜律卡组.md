# 12. 卡牌补充：炎刃 15 张 & 霜律 15 张（建议稿）

> 性质：**设计建议稿**，不是转录件。炎刃 5 张原始卡（Era 提供）的名称 / 费用 / 力量 / 原文一律不动；
> 8 张占位卡中 7 张补效果、1 张保留白板；新增 2 张。霜律为全新体系。
>
> 依据：`docs/10-卡牌样例.md`、`docs/06-规则与界面输入表.md`、`ADR-0018`（占位卡）、

>
> 口径（Era 2026-10-19 确认）：
>
> 1. 炎刃「到 15 张」= **含指挥官共 15 张** → 现有 13 张，补 **2 张**。
> 2. 允许白板卡，但**绝大多数卡要有完整效果**；可以没有白板。
> 3. 新体系走 **霜律 · 冻结控制**。

## 0. 先读：15 张是「体系」，不是一副合法卡组

现有构筑规则（A6-5 / A10-4）：**主卡组 30 张 + 指挥官 1 张**，同名上限 3。
所以本文的「15 张」指一个体系的**卡池**，不是一副能直接开局的 15 张牌。

- 15 张 × 最多 3 张 = 45 张，足够组出 30 张主卡组；
- 文末 §8 给出两套**合法**的 30 张示例构筑；
- 如果你的本意是「一副 15 张的快速局规则」，那是另一套构筑规则，需要单独定，本文不擅自改。

## 2. 炎刃逐卡文本

### 2.1 指挥官（原文不动）

**炎刃军统领** `bladeLord`

```
力量值0-1-3-5 力量值提升，在每回合充能阶段执行
Ⅰ 【2】每回合一次，可以根据除外区的卡名包含炎刃的卡的数量执行以下最多3个效果，每个效果最多一次：
  1个：从墓地选择一个力量值在除外区炎刃数量等级以下的随从，召唤
  3个：选择一个随从，本回合力量值+1
  5个：选择一个力量值在除外区炎刃数量等级以下的随从，破坏
  7个：选择一个随从，本回合对指挥官伤害+1
  9个：选择一个随从，一回合一次，攻击后重置
Ⅱ 每回合一次，可以将一张手牌除外。
```

> 9 档文字按 Era 2026-10-19 拍板（H23）使用「一回合一次，攻击后重置」。
> `powerCurve` 仍为 `[0,1,3,5]`，充能阶段推进，末档封顶。
>
> **除外区就是炎刃的 token 池**：只有卡名含「炎刃」的卡计入，数量**永久累积、不随回合清零**。
> 这是炎刃独有的成长轴——斥候/卫士/骑士/老兵/焚典/凤凰负责往里堆，统领 Ⅰ 负责按 1/3/5/7/9 档兑现。
> 霜律对应的是**霜痕**（见 §4.1 裁决官 Ⅲ）：冻结发生就累积，永久不清零。
> 一个主动投资（送墓 → 除外），一个被动沉淀（冻结 → 留痕），两者的成长手感不同。

将卡组顶一张卡片置入伤害区。

### 2.3 2–3 费

**炎刃卫士** `bladeGuard` — 2 费 / 2 力 / 嘲讽

```
【2】随从 / 力量值2 / 嘲讽
登场时：将卡组顶一张卡置入墓地；若该卡卡名包含「炎刃」，你可以将其除外。
```

> 2 费 2 力 + 嘲讽是按「嘲讽 −1 力」的旧规则；置入墓地 1 张是小型填墓/填除外，不额外加力。
> 它是炎刃少有的防御牌，也是把「卡组顶」变成资源的入口。

**炎刃骑士** `bladeKnight` — 3 费 / 4 力

```
【3】随从 / 力量值4
攻击时：你可以将墓地一张卡名包含「炎刃」的卡除外；若如此做，本回合此卡力量值+1。
```

> 设计上是「用墓地换力量」：填除外与抢场面二者只能选一个，构成炎刃的核心取舍。
> 攻击时触发，力量值快照在触发之后（H9），所以 +1 能参与当次裁决。

**炎刃战术** `bladeTactics` — 2 费法术

```
【2】法术
选择一个己方随从：本回合其力量值+2。
若你的除外区有3张以上卡名包含「炎刃」的卡，改为+3。
```

> 纯战斗技巧。2 费 +2 是基准；+3 需要 3 张除外，作为体系奖励。
> 由于当前不开放对手回合响应（H7），它只能在己方主要阶段使用，定位是「主动换牌」而非「反制」。

**炎刃焚典** `bladeCremation` — 2 费法术（新增）

```
【2】法术
展示卡组顶4张卡。将其中任意数量的卡名包含「炎刃」的卡除外，其余置入墓地。
```

> 炎刃缺的从来不是「除外收益」，而是**稳定的除外入口**。这张牌一次最多填 4 张除外，
> 同时把没选中的牌送进墓地，供骑士/老兵/统领 1 档回收。
> 「任意数量」是刻意留的选择：手牌/墓地已经够用时，可以少除外，保留后续回收资源。
> 2 费是它和「号令」（1 费、兑现向）之间的分工线。

**炎刃战旗** `bladeBanner` — 3 费持续法术

```
【3】持续法术
每回合一次：当一张卡名包含「炎刃」的卡被除外时，抽一张牌。
```

> 炎刃的续航引擎。每回合一次，防止多张同时除外的爆发式抽牌。
> 与统领 Ⅱ、骑士、老兵、焚典、凤凰都能联动。

### 2.4 4–7 费

**炎刃队长** `bladeCaptain` — 4 费 / 5 力

```
【4】随从 / 力量值5
每当你有一个其他卡名包含「炎刃」的随从登场时，该随从本回合力量值+1。
```

> 「其他」排除自身，避免 5/5 落地自带 +1。
> 它是铺场路线的中场核心：先队长、后跟两个炎刃，等于全队当回合 +1。
> 触发口径与军师一致（登场即触发，含效果召唤）。

**炎刃老兵** `bladeVeteran` — 5 费 / 6 力

```
【5】随从 / 力量值6
登场时：你可以将墓地一张卡名包含「炎刃」的卡除外；若如此做，抽一张牌。
```

> 5 费 6/6 的身材 + 条件抽 1。把「墓地里的炎刃」变成手牌，同时给统领堆除外数。
> 与骑士抢墓地，是中期的主要决策点。

**炎刃勇士** `bladeChampion` — 6 费 / 7 力

```
【6】随从 / 力量值7
登场时：你的除外区每有3张卡名包含「炎刃」的卡，本回合此卡力量值+1（最多+3）。
```

> 6 费 7/7 的基准终结者；除外区 9 张时当回合 10/7。
> 它是「除外计数」最直接的兑现口，和统领 Ⅰ 的 9 档同一套计数。

**炎刃凤凰** `bladePhoenix` — 7 费 / 7 力 / 伤害 2（新增）

```
【7】随从 / 力量值7 / 伤害值2
登场时：将你墓地中所有卡名包含「炎刃」的卡除外。
每除外一张，本回合此卡力量值+1（最多+5）。
```

> 炎刃的顶费终结者，也是「墓地 → 除外 → 力量」的闭环：
> 一次把墓地清空成除外数，当回合最多 12/7，且伤害 2（两次攻击即可打掉 4 血）。
> 它同时把统领 Ⅰ 的 7 / 9 档解锁，是「一张牌同时兑现两个系统」的设计。
> 7 费在 1→3→5→10 的费用曲线下是可打出的，但需要前期主动充能，属于明确的构筑代价。
> ⚠️ 伤害 2 会按 A5 补充 1 让对手展示 2 张卡进费用区——打脸的同时也在给对手送费用，
> 所以它是「抢血终结」而不是「无脑打脸」。

## 4. 霜律逐卡文本

### 4.1 指挥官

**霜律裁决官** `frostAdjudicator`

```
力量值0-1-2-4 力量值提升，在每回合充能阶段执行
Ⅰ 【2】每回合一次：霜冻一个敌方随从。按霜痕层数升级：
  0–2 层：霜冻 1 个
  3–5 层：霜冻 1 个，抽 1 张
  6–8 层：霜冻 2 个
  9 层+：霜冻 2 个，抽 1 张
Ⅱ 每回合一次：当一个敌方随从被霜冻时，抽一张牌。
Ⅲ（霜痕）每当一个敌方随从被霜冻，你获得 1 层霜痕。霜痕永久累积。
```

> 力量曲线比炎刃慢一档（0-1-2-4 对 0-1-3-5）：霜律不是靠指挥官打输出，而是靠它每回合
> 「2 费换 1 次冻结 + 1 张牌」把对局拖长。Ⅱ 覆盖所有冻结来源（法术、随从、自身 Ⅰ），
> 但每回合只抽 1 次，避免号令式爆发抽牌。
>
> **Ⅲ 是霜律的成长轴**：冻结是消耗性的（对手下回合就醒），但霜痕把它沉淀下来。
> 实测每局能堆到 6–7 层，第 3–4 轮走到「冻 2 个」这一档——玩家每一轮都能看到层数变化，
> 又不会一轮跳两级。和炎刃的除外区相比：炎刃要主动“造”资源（送墓 → 除外），
> 霜律是冻结发生就自动累积，一个主动投资、一个被动沉淀。
>
> Ⅰ 的 2 费是**费用区的 2 张卡**（与统领【2】同一口径，ADR-0023）。

### 4.2 0–2 费

**霜律新兵** `frostRecruit` — 0 费 / 1 力

```
【0】随从 / 力量值1
```

> 白板。0 费 1/1 是充能位，也是「先手第 1 回合有牌可出」的保底。

**霜律学徒** `frostApprentice` — 1 费 / 1 力

```
【1】随从 / 力量值1
登场时：霜冻一个敌方随从。
```

> 1 费 1/1 是「带效果随从比白板低 1 力」的标准价。落地即冻结，负责把对手的
> 2 费/3 费节奏往后拖一回合。

**霜律戍卫** `frostWarden` — 1 费 / 1 力 / 嘲讽

```
【1】随从 / 力量值1 / 嘲讽
当此卡被攻击时，攻击者本回合力量值-1。
```

> 1 费 1/1 嘲讽已经是「嘲讽 −1 力」的底线；被攻击时再 −1，是让 1–2 力攻击者
> 直接撞死/同归于尽的防御牌。它的价值不在身材，而在于逼对手多付一张牌来解。

**霜律缚锁者** `frostBinder` — 2 费 / 2 力

```
【2】随从 / 力量值2
登场时：霜冻一个敌方随从；若该随从已处于霜冻状态，改为抽一张牌。
```

> 对「已经冻住」的目标不浪费：重复冻结转成抽牌。它和裁决官 Ⅱ 同回合可以抽 2 张
>（缚锁者 1 张 + 裁决官 1 张），是霜律少有的爆发补牌点。

**霜律长枪兵** `frostLancer` — 2 费 / 2 力

```
【2】随从 / 力量值2
此卡攻击处于霜冻状态的随从时，力量值+2。
```

> 霜律的「兑现」牌：2 费 2/2 平时偏弱，但打冻结目标时是 4/2，可以吃掉 3–4 力的单位。
> 它要求你先冻结、再攻击，正好把「控制」转成「场面」。

### 4.3 3–4 费

**霜律执法者** `frostEnforcer` — 3 费 / 3 力

```
【3】随从 / 力量值3
每当一个敌方随从被霜冻时，本回合此卡力量值+1，每回合最多+2。
```

> 3 费 3/3 的标准价；一场「寒流/守夜人/典狱长」的群体冻结能让它当回合长到 5/3。
> 上限 +2 是防止「终裁前置」或多次冻结把力量堆到不可交互。

**霜律守夜人** `frostNightwatch` — 4 费 / 4 力

```
【4】随从 / 力量值4
登场时：霜冻至多两个敌方随从。
```

> 4 费 4/4 的标准价；双冻结是中期最大的节奏点。它不直接杀单位，但能让对手
> 一个战斗阶段少两次攻击，等于用 4 费买一回合。

**霜律寒域** `frostDomain` — 3 费持续法术

```
【3】持续法术
敌方处于霜冻状态的随从力量值-1。
```

> 把「冻结」从「少一次攻击」升级成「少一次攻击 + 战力下降」。
> 与长枪兵（打冻结 +2）、执法者（冻结成长）、审判（冻结破坏）三张牌同时联动。
> 3 费是永续光环的基准价；它本身不产生节奏，属于优势滚雪球牌。

### 4.4 5–6 费

**霜律典狱长** `frostJailer` — 5 费 / 5 力

```
【5】随从 / 力量值5
登场时：霜冻所有敌方随从。
```

> 5 费 5/5 的标准价；全体冻结是霜律的「回合买断」。对手下回合的**现有随从全部不能攻击**，
> 你获得一次安全的进攻窗口；对手仍可正常出牌，只是要用新牌重建攻势。

**霜律凛冬之刃** `frostWinterblade` — 6 费 / 6 力 / 伤害 2

```
【6】随从 / 力量值6 / 伤害值2
登场时：霜冻所有敌方随从。
```

> 霜律的终结者：6/6 身材 + 全体冻结 + 伤害 2。冻结压住对手现有场面，让它落地当回合
> 能安全进攻；伤害 2 让 15 血在 5–6 次攻击内见底。它是「控制转斩杀」的那张牌。

### 4.5 法术

**霜律律令** `frostEdict` — 1 费法术

```
【1】法术
霜冻一个敌方随从；若其力量值大于等于4，抽一张牌。
```

> 1 费冻结是标准价；对 4 力以上目标补 1 张，是对「高费大哥」的针对性补偿。
> 它也是裁决官 Ⅱ 之外最便宜的触发源。

**霜律寒流** `frostColdSnap` — 2 费法术

```
【2】法术
霜冻至多两个敌方随从。
```

> 2 费换两次「少一次攻击」。在 3 个随从位的场上，它最多冻 2 个，不会一键全锁。
> 与守夜人（4 费 4/4 + 双冻结）形成「法术版 / 随从版」的分工。

**霜律审判** `frostJudgment` — 3 费法术

```
【3】法术
选择一个敌方随从：若它处于霜冻状态，破坏它；否则霜冻它。
```

> 霜律的定点解。它不能直接杀，必须先有冻结；但「否则霜冻它」保证它永远不是废牌。
> 3 费是「条件破坏」的基准价（无条件破坏应更贵）。

**霜律终裁** `frostFinalJudgment` — 5 费法术

```
【5】法术
破坏所有处于霜冻状态的敌方随从。每破坏一个，对敌方指挥官造成1点伤害。
```

> 霜律的收场牌：先冻结、再清场、再烧脸。3 个随从位最多打 3 点，5 费是合理的
>「群体条件破坏 + 直伤」价。它要求你先投入冻结资源，不是无脑清场。
> ⚠️ 每 1 点直伤也会按 A5 补充 1 让对手展示 1 张进费用区——清场之后对手反而更富，
> 所以它最好接在「对手已经没有手牌/费用区也撑不起下一波」的时点。

## 5. 新关键词：霜冻（Frozen）

### 5.1 规则文本

> **霜冻**：被霜冻的单位立即进入休眠，并标记为「霜冻」。
> 其控制者的**下一个回合**的重置阶段不重置它；该回合结束时解除霜冻。
> 之后它照常重置。

### 5.2 时序（以「你的回合冻结敌方 A」为例）

| 时点 | A 的状态 | 说明 |
| --- | --- | --- |
| 你的回合，冻结生效 | 休眠 + 霜冻 | 立即休眠；当回合不能再攻击（本来也不是它的回合） |
| 对手回合，充能 | 休眠 + 霜冻 | 充能阶段可把 A 置入费用区（霜冻不阻止充能） |
| 对手回合，重置 | **不重置**，仍休眠 + 霜冻 | 这是霜冻的核心：跳过 1 次重置 |
| 对手回合，战斗 | 休眠 + 霜冻 | 不能攻击；仍可被攻击、仍可被效果指定 |
| 对手回合，结束 | 解除霜冻，仍休眠 | 该回合结束才解除，保证「寒域」等光环覆盖整个被冻回合 |
| 再下一个对手回合，重置 | 正常重置 | 恢复行动 |

**净效果**：被冻单位少一次攻击机会。不是「少两个回合」，也不是「不能被选为目标」。

### 5.3 边界与裁决

| 问题 | 结论 | 理由 |
| --- | --- | --- |
| 霜冻是否叠加？ | **否**。对已霜冻单位再次霜冻，只刷新「跳过下一次重置」 | 避免「冻 N 次 = 锁 N 回合」的滚雪球 |
| 霜冻单位能否被攻击？ | **能** | 它只是休眠，不是离场/隐匿 |
| 霜冻单位能否被效果指定？ | **能** | 同上 |
| 霜冻单位能否被充能？ | **能** | 充能是控制者的主动动作，霜冻只限制重置 |
| 霜冻是否影响指挥官？ | **只影响随从**（本文所有卡都写「敌方随从」） | 指挥官的力量曲线与掉血是另一套系统，先不交叉 |
| 减力下限 | **0**，不为负 | 与 A6 力量值 0–65535 的取值范围一致 |
| 霜冻与「攻击后休眠」 | 可叠加效果：先攻击（休眠）→ 再被冻 → 跳过下一次重置 | 等于多罚一回合，属于控制牌的正当收益 |
| 霜冻单位被破坏 / 离场 | 标记随实例消失，不进入墓地/除外区 | 状态属于实例，不属于卡定义 |
| 在自己回合被霜冻（自冻牌） | **暂不定义**：本文没有自冻牌 | 现有冻结全部由对方在自己回合施加；将来出现自冻牌时再补「当前回合是否立即少一次攻击」 |

### 5.4 A7 关键词表建议新增行

| 关键词 | 触发时机 | 精确效果 | 是否可叠加 | 备注 |
| --- | --- | --- | --- | --- |
| 霜冻 | 被效果赋予时 | 目标立即休眠；其控制者的下一个回合重置阶段不重置；该回合结束解除 | 否 | 只影响重置，不影响被攻击/被指定/被充能 |
| 霜痕 | 每个敌方随从被霜冻时 | 该玩家获得 1 层霜痕，永久累积、不随冻结解除或随从离场减少 | 是（层数累加） | 目前只有霜律裁决官读取；不改变冻结本身 |

> `霜冻` 不是 `CardDef.keywords` 里的常驻关键词，而是 `CardInstance` 的**状态位**；
> A7 登记它是为了给「被霜冻时」的触发一个正式时机名。

## 6. 两套体系的构筑逻辑

### 6.1 炎刃：除外计数 → 分档兑现

**指挥官就是引擎**：

- Ⅱ 每回合把 1 张手牌除外 → 稳定 +1 除外数；
- Ⅰ 按除外区的「炎刃」数解锁 1 / 3 / 5 / 7 / 9 档，每回合最多选 3 项；
- 除外数既是「解禁条件」，也是「召唤/破坏的力量上限」。

**15 张的分工**：

| 角色 | 卡 |
| --- | --- |
| 填除外 | 斥候、卫士、骑士、老兵、焚典、凤凰 |
| 兑现除外 | 统领 Ⅰ、军师、勇士、战旗 |
| 铺场/充能 | 先锋、新兵、队长 |
| 战斗技巧 | 战术 |

**节奏**：

1. 1–3 回合：铺 0–2 费，尽量让卫士/斥候/骑士把墓地与除外区各填一点；
2. 3–5 回合：用统领 Ⅰ 的 1 档回收、3 档加力、5 档解场；
3. 5–7 回合：老兵/战旗补牌，勇士压场；
4. 7 费后：凤凰清空墓地 → 当回合 12/7 + 解锁 7/9 档，进入收尾。

**弱点**：

- 除外/墓地没铺起来时，统领只有 1 档，整套牌会变成「白板中速」；
- 怕比它更快的铺场：3 回合前被打到 10 血以下，后面很难用 5 费牌翻回来；
- 骑士/老兵/凤凰都在抢墓地，容易出现「除外了不该除外的卡」。

### 6.2 霜律：冻结 → 拖回合 → 用节奏差赢

**指挥官就是引擎**：

- Ⅰ：2 费 = 1 次冻结（每回合一次）；
- Ⅱ：任意来源冻结敌方随从 → 抽 1（每回合一次）。

也就是说，霜律每回合的基准动作是「花 2 费，冻结一个威胁，抽一张牌」。
它不靠指挥官打伤害（曲线只有 0-1-2-4），而是靠这张牌把对手的进攻回合变成空过。

**15 张的分工**：

| 角色 | 卡 |
| --- | --- |
| 冻结入口 | 学徒、缚锁者、守夜人、典狱长、凛冬之刃、律令、寒流 |
| 冻结兑现 | 长枪兵（打冻结 +2）、执法者（冻结成长）、审判（冻结破坏）、终裁（群体破坏） |
| 防守 | 戍卫（嘲讽 + 攻击者 −1）、寒域（冻结 −1 力） |
| 充能/前期 | 新兵 |

**节奏**：

1. 1–2 回合：学徒/戍卫站场，优先冻住对手的 2–3 费攻击手；
2. 3–4 回合：寒域落地，把「冻结」变成「−1 力」，长枪兵开始吃人；
3. 4–5 回合：守夜人/典狱长双冻/全冻，执法者当回合长力；
4. 5 费后：审判点掉大个，终裁清场烧脸；
5. 6 费：凛冬之刃全冻 + 2 伤，配合指挥官收尾。

**弱点**：

- 自身力量低：除了凛冬之刃，最高只有 5/5；被抢血时很难靠身材翻盘；
- 对手不出随从时，Ⅰ/Ⅱ 都会熄火（这是刻意的「反控制」弱点）；
- 非常依赖指挥官站场：裁决官一死，冻结入口少一半，所以戍卫/寒域的保护很关键。

## 7. 数值预算与平衡

### 7.1 本次采用的三条线

| 线 | 规则 | 例子 |
| --- | --- | --- |
| 白板随从 | `power = cost + 1` | 先锋 1/2、新兵 0/1 |
| 带效果随从（常规） | `power = cost`（比白板低 1） | 学徒 1/1、缚锁者 2/2、执法者 3/3、守夜人 4/4、典狱长 5/5 |
| 强效果 / 终结者 | `power = cost - 1`，或费用 +1，或伤害值换力量；例外见下 | 凛冬之刃 6/6 / 伤害 2；凤凰 7/7 / 伤害 2 |

> 例外：勇士 6/7 保留白板身材，因为它的 +1/+2/+3 要在除外区攒够 3/6/9 张才兑现，
> 属于「延迟收益」，用「先付场面、后收力量」抵掉了折价。

**嘲讽**：额外 −1 力（沿用旧规则）。例：戍卫 1 费 1/1 嘲讽、卫士 2 费 2/2 嘲讽。

**法术**（经验价，不是公式）：

| 费用 | 效果量级 | 例子 |
| --- | --- | --- |
| 1 | 冻结 1 个 | 律令 |
| 2 | 冻结 2 个 / 展示 4 张做资源 / 单体 +2–3 力 | 寒流、焚典、战术 |
| 3 | 条件破坏 / 永续光环 | 审判、寒域 |
| 5 | 群体条件破坏 + 直伤 | 终裁 |

### 7.2 两套的强度差

| 维度 | 炎刃 | 霜律 |
| --- | --- | --- |
| 身材 | 高（6/7、7/7、可成长到 10–12） | 低（最高 6/6） |
| 解场 | 依赖统领 5 档 + 战斗 | 审判、终裁、寒域、冻结 |
| 续航 | 墓地回收 + 战旗抽牌 | 裁决官 Ⅱ + 缚锁者 + 律令 |
| 节奏 | 中速铺场 → 大哥压场 | 控制 → 拖回合 → 终结者 |
| 明显弱点 | 前期空档、抢墓地 | 低力量、依赖指挥官 |

设计意图是**炎刃偏「中速价值」、霜律偏「控制」**，不是五五开的镜像。
如果你要的是严格五五开，优先调 §7.3 的旋钮。

### 7.3 平衡旋钮（实测偏强/偏弱时先动这些）

| 方向 | 卡 | 调整 |
| --- | --- | --- |
| 炎刃偏强 | 队长 | 5 力 → 4 力 |
| 炎刃偏强 | 老兵 | 6 力 → 5 力 |
| 炎刃偏强 | 凤凰 | 上限 +5 → +3 |
| 炎刃偏强 | 战旗 | 3 费 → 4 费，或改为「每回合合计一次」 |
| 炎刃偏弱 | 焚典 | 2 费 → 1 费 |
| 霜律偏强 | 寒域 | 3 费 → 4 费 |
| 霜律偏强 | 终裁 | 5 费 → 6 费 |
| 霜律偏强 | 裁决官 Ⅰ | 【2】→【3】（冻结从「每回合固定动作」变成「要衡量费用」） |
| 霜律偏弱 | 凛冬之刃 | 6 力 → 7 力，或伤害 2 → 3 |
| 霜律偏弱 | 审判 | 3 费 → 2 费 |

## 9. 落地要点（如果要进代码）

### 9.1 数据层

- `CARD_POOL` 新增 17 个 `CardDef`：炎刃 2 张 + 霜律 15 张；
- 炎刃 8 张占位卡中 **7 张补 `text`、1 张（新兵）保留白板**（数值均不变），
  并把 8 张整体从 `PLACEHOLDER_CARD_IDS` 移出——它们不再是「占位」，而是正式卡；
