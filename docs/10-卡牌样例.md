## 术语别名（重要）

Era 的输入里，**同一个区域出现过三个名字**，已由 Era 明确确认等同：

| 别名 | 出现位置 | 实际区域 |
| --- | --- | --- |
| **费用区** | A5 补充、B2 布局 | `cost` |
| **充能区** | X-2 补充第 2 条 | `cost`（Era 2026-10-13 确认） |
| **伤害区** | 卡牌样例卡面文本（炎刃斥候） | `cost`（Era 2026-10-13 确认） |

同理，「弃牌区」（卡面文本）= 弃牌区（`graveyard`）。

> ⚠️ 别名只出现在文档与注释，**不进代码标识符**。若给 `Zone` 再加一个 `'damage'` 值，
> 就等于制造了两个指向同一处的区域，之后所有按区域查找都要处理这个伪区分。

### 炎刃军统领（指挥官）

```
力量值0-1-3-5 力量值提升，在每回合充能阶段执行
Ⅰ 【2】每回合一次，可以根据除外区的卡名包含炎刃的卡的数量执行以下最多3个效果，每个效果最多一次：
  1个：从弃牌区选择一个力量值在除外区炎刃数量等级以下的随从，召唤
  3个：选择一个随从，本回合力量值+1
  5个：选择一个力量值在除外区炎刃数量等级以下的随从，破坏
  7个：选择一个随从，本回合对指挥官伤害+1
  9个：选择一个随从，本回合攻击后重置
Ⅱ 每回合一次，可以将一张手牌除外。
```

**转录方式**：力量值是曲线不是定值，故 `power` 记**初始档位的值 0**，完整曲线置于 `powerCurve = [0,1,3,5]`，原始文本存 `text`。

**曲线推进（X-7 / ADR-0016，Era 2026-10-13 原话「是初始0然后每个充能阶段成长，第一回合就会变到1」）**：
`powerCurve` 是**档位序列**而非「回合号 → 力量值」映射 —— 开局取第 0 档（值 0），每经过一次**己方**充能阶段推进一档；
故第 1 回合后为 1、第 2 回合后为 3、第 3 回合后为 5，之后封顶保持 5。战斗裁决读当前档位的力量值。

### 炎刃斥候（随从）

```
【0】随从 / 力量值1
这张牌从卡组展示时，可以被除外，如果除外且被展示的这张卡本应置入伤害区，
将卡组顶一张卡片置入伤害区。
```

**这条卡面文本确认了两件事**：

1. 「**展示时**」确实是一个触发时机 —— 与 A5 补充 1 的「如有效果则触发对应效果」对上了。
2. 存在**可选动作**（「**可以**被除外」），需要玩家做选择 —— 与待决策 **D4 `pendingChoice`** 直接相关。此前 D4 是「建议等 A4-3/A7 再定」，现在它有了真实使用场景。
