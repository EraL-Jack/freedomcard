## 一、需要你拍板（8 条）

### P-01 · 40 轮判和：留、改、还是删

- **现状**：`TURN_LIMIT_ROUNDS = 40`（`shared/constants.ts:180`）→ 全局回合 80；`rules/phase.ts:86`
  在 `nextTurn > 80` 时发 `game:ended { winner: '', reason: 'draw' }`。判和**不计分但消耗一局**
  （`room/room.ts:268`）。
- **真正的麻烦在 BO3**：`recordGameResult` 只认「有人拿到 2 胜」才收系列赛，
  **没有局数上限**。三局若打成「平 / 胜 / 负」= 1:1，leader 永远不存在 → 房间停在
  `awaitingNext`，房主可以无限开下一局。这条不是规则口径问题，是**收不了尾**。
- **代价**：40 轮在 8 血节奏下约 20~30 分钟，正常对局见不到；一旦触发，BO3 会卡在等待态。
- **选项**：① 保留判和 + 给 BO3 加「最多 3 局，打满按胜场、平手按血量/手牌裁定」；
  ② 保留判和 + BO3 判和时双方各记 0.5 胜（2 局就能收）；③ 删掉判和（无上限对局）。
- **推荐**：②。改动最小、语义最直（平局算半胜，1.5 胜即拿系列赛），且不需要「血量比大小」这种新规则。
  **另需你确认一句**：BO3 打满 3 局仍 1:1（两胜一平之外的情况）算谁赢？我的默认建议是**判平、系列赛无人获胜**。

### P-02 · 结算只看得到「胜利 / 败北」，看不出**为什么**

- **现状**：`TableScreen.tsx:427-451` 结算面板只有两行 —— 大标题（胜利 / 败北 / 平局）
  与一行比分（`BO3 · 第 N 局结束 · 比分 我 X : Y 对手`）。BO1 平局那行会显示「40 轮未分胜负」。
- **缺的能力**：分不清「血量被打到 0」「自己认输」「对手掉线判胜」「40 轮判和」。
  同一句「败北」有四种成因，复盘时全靠回忆。
- **代价**：玩家以为自己被规则坑了；你验收时也无法从截图判断败因。
- **选项**：① 结算第三行加一句成因（`对方指挥官生命归零` / `你已认输` / `对手掉线超时` / `40 轮未分胜负`）；
  ② 再补关键数字（剩余血量、双方回合数、最后一击）。
- **推荐**：①，一句话，不改协议（`game:ended` 的 `reason` 已经在）。
  ② 建议**不做**，信息密度够了就停，免得结算页变成报表。

### P-03 · 零新手引导

- **现状**：主界面就是「建房 / 加入 / 编辑卡组」三个入口（`HomeScreen`）；卡面只有效果描述，
  没有一句规则说明。新玩家开局不知道要「先充能再出牌」，也不知道「随从没有生命值、
  只比力量」。
- **代价**：目前只有你和你朋友在玩，问题不大；一旦发给第三个人，第一分钟就跑。
- **选项**：① 首局进入对战桌时给 3 步浮层提示（充能 → 推进阶段 → 出牌），只出现一次；
  ② 主界面加一页「怎么玩」（静态图文，半屏）；③ 不做。
- **推荐**：①。成本最低、命中真实卡点，且不引入新页面。文案我起草，你改字即可。

### P-04 · 输入表说「允许在对手回合行动」，实现是「只能在自家回合」

- **现状**：`docs/06:77` A4-3 填的是「**是**」；`docs/09` H7 记的是「暂不开放：所有 Intent
  限定在自家回合」，由 `baseGuard` 一条守卫拦住。**输入与实现相反**，且 H7 至今未确认。
- **代价**：以后想加「响应 / 陷阱 / 打断」时，会以为地基已经支持，实际要从守卫这层重做。
- **选项**：① 维持现状，把 A4-3 改成「第一版不做」（改输入表，加注说明）；
  ② 真做响应窗口（工作量大：`pendingChoice` 之外还要一套「对方可插入」的时序）。
- **推荐**：①。第一版没有陷阱类卡，现在做响应窗口是给未来买单。

### P-05 · 旁观位

- **现状**：协议只有 `room:create` / `room:join` / `room:deck`，没有 `spectate`；
  房间 `capacity` 1–8（`schema.ts:74`）但席位语义、观战推送都没有。
- **代价**：你没法「看朋友对局」；也没法一边打一边让人围观。
- **选项**：① 不做（第一版不需要）；② 只做「观战只读」：`room:watch` + 复用 `game:events`
  广播、客户端隐藏所有操作按钮。
- **推荐**：① 先不做。但**顺带要处理** P-05 的邻居：`capacity` 允许 3~8 人会建出
  「三人大乱斗」房间，而规则只验证过 2 人 —— 这条我按 T-07 自己收口（把 UI 收到 2 人）。

### P-06 · X-15 素材（卡图 / 音效 / 特效）

- **现状**：`docs/19 §2` 列了三类要你给的东西，目前全空 —— 卡面是纯色 + 文字，
  音效只有一个未接线的钩子，特效是 CSS 过渡。
- **代价**：观感停在「能玩」；你自己也说「太挫」过一次（D-185）。
- **选项**：① 继续占位，等你有空出图；② 先定「一套 15 张的美术方向 + 1 个音效包」，
  我按方向找开源素材填进去（注意授权）；③ 只做音效（打击 / 抽牌 / 结算三条），卡图继续占位。
- **推荐**：③。音效对「打得爽不爽」的边际收益远高于卡图，且不涉及美术风格拍板。
  卡图等你给方向（X-14 的配色也一起），避免我猜错风格白做。

### P-07 · `damage` 字段的取值范围

- **现状**：`docs/09:85` 仍未销项 —— 默认值 1（X-5）已定，但**上限、能否为 0、能否为负**没定。
  战斗侧目前按「卡面写了就以卡面为准」直接吃这个值（`DEFAULT_DAMAGE = 1` 兜底）。
- **代价**：如果以后写 0 或负数的卡，会造成「打脸不掉血」或「给对方加血」这类静默怪象，
  而且单元测试不会报错（没人断言范围）。
- **选项**：① 只允许 ≥1 的整数（写 0 / 负数在加载卡池时就报错）；② 允许 0（= 纯效果卡）。
- **推荐**：①。本作伤害就是「打脸几点」，0 伤害的随从没有存在意义；
  真要「纯效果」就用 `type: 'spell'`。
