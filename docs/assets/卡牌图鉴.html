FREEDOM CARD · CARD SET REVIEW

炎刃 15 · 霜律 15

炎刃补齐到含指挥官 15 张；霜律是一套全新的「冻结控制」体系。 两套都按 30 主卡组 + 1 指挥官的构筑规则设计，卡面数值与完整规则见配套 Markdown 设计稿。

炎刃：除外计数 → 分档兑现，中速价值。
霜律：冻结拖回合 → 节奏差 → 终结者。
霜冻：立即休眠，跳过 1 次重置，不叠加。
新增 / 补效果 / 原始 / 白板 四类标签。

炎刃

除外 / 墓地 / 分档 · 指挥官曲线 0→1→3→5 15 张

指挥官 Ⅱ 每回合把手牌变成除外数，Ⅰ 按 1/3/5/7/9 档兑现。新增的两张牌分别补「稳定除外入口」（焚典） 与「顶费终结者」（凤凰）；8 张原白板里有 7 张补了与除外/墓地联动的效果，只留新兵当 0 费充能素材。

霜律

冻结 / 休眠 / 控制 · 指挥官曲线 0→1→2→4 15 张

指挥官用「2 费 + 1 次冻结」换节奏，Ⅱ 把每一次冻结转成一张牌。整套牌不追求身材，而是先把对手的 攻击回合按停，再用长枪兵 / 执法者 / 寒域把这次停顿换成场面，最后由审判、终裁与凛冬之刃收尾。

霜冻是什么被霜冻的单位立即休眠；其控制者的下一个回合重置阶段不重置它，该回合结束解除。净效果 = 少一次攻击。
不是什么不是「不能成为目标」，不是「锁两个回合」，不叠加。被冻单位仍可被攻击、被效果指定、被充能。
怎么兑现寒域让冻结单位 −1 力；长枪兵打冻结目标 +2；执法者每次冻结成长；审判/终裁把冻结变成破坏。
口径：含指挥官共 15 张；允许白板，但绝大多数卡有完整效果；霜冻 = 跳过 1 次重置。 卡面文本为展示用精简版，完整规则、边界裁决、数值预算、两套 30 张示例构筑与落地要点以配套 Markdown 设计稿为准。
数据基线：主卡组 30 + 指挥官 1，同名上限 3；力量值比较裁决；伤害值默认 1。
